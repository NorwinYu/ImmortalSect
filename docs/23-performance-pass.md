# 23 · 性能优化：372 → 273-279 draw calls

> 目标：先让山门回到 300 calls 以内，再谈加内容。

---

## 23.1 问题

优化前山门 **372 draw calls**：

- 试剑傀儡 **42 个 mesh**，无论是否在战斗都常驻并投射阴影；
- 8 栋建筑各有一个 Sprite 文字标签，和 DOM 标记重复；
- 群像、建筑、植被、玩家细节叠加。

---

## 23.2 处理

### 1. 傀儡休眠合并

- 傀儡在 `dormant` 时不再使用 42 个独立 mesh。
- 把所有身体几何按世界变换烘焙成 **1 个顶点色 mesh**：
  - 木、铜、钢、布、符文、眼睛的颜色写进顶点色；
  - 保留一个统一材质。
- 只有 `activate()` 时才显示完整骨架（42 mesh），用于攻击/受击/死亡动画。
- `reset()`、战败、离开试剑台、**胜利结算**都切回休眠 1 mesh。
- 试剑台的符文圈和警戒环保留。

### 2. 移除建筑 Sprite 标签

- 建筑已经有 DOM 投影标记（名称/等级/施工状态）。
- Sprite 标签在近距离和 DOM 标记重复，直接移除。
- `makeLabel` / `labelHeight` 删除，不再创建 CanvasTexture。

## 23.4 代价

- 休眠傀儡是一个合并剪影，近看不如完整骨架细。
- 战斗时仍是完整 42 mesh；P4 通过玩家静态部件合批，把试剑 calls 压到 257。
- 建筑近处不再有 Sprite 文字，只保留 DOM 标记；标记会随距离缩放/隐藏，并做屏幕空间避让。
- P3 时玩家本体是 71 个 mesh；P4 已按材质合并静态部件，同时保留手臂/腿/头/剑的 Group 动画，当前为 31 个 mesh。
