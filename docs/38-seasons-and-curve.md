## 38.1 季限事件（4 段，各一次）

仅在**自由修行**、且进入对应节气的日子出现，作为保底候选卡：

| 事件 | 节气 | 选项（二选一） |
|---|---|---|
| `season_spring` 春 · 灵雨 | 春（第 1-3 日） | 开圃接雨（药材 +30 / 士气 +3 / 香火 +1）或 静坐听雨（心得 +5 / 道心 +2） |
| `season_summer` 夏 · 地火 | 夏（4-6 日） | 就地铸剑（灵石 -20 / 声望 +6 / 香火 +1）或 避火闭关（顾长风修为 +15 / 道心 +2） |
| `season_autumn` 秋 · 丰稔 | 秋（7-9 日） | 封仓入库（灵石 +40 / 药材 +15）或 分粮与弟子（士气 +5 / 全体忠诚 +4） |
| `season_winter` 冬 · 玄冰 | 冬（10-12 日） | 亲自下崖取髓（心得 +6 / 香火 +2 / 掌门受伤）或 守岁温酒（士气 +6 / 声望 +3 / 道心 +2） |

- 「天材地宝」落到既有的 **香火** 上（可去香火天梯换永久增益），不新造资源；
- 每段 `when` 同时校验 `freeMode` 与 `!seenEvents.includes(id)`，故每局各触发一次；
- 接入 `buildCandidates` 的保底位（与时代事件、寻回支线同层），并加入 `getEvent` 回退链。

## 38.2 要务难度曲线

`rollObjective` 的目标值现在带难度系数：

```
difficulty = 1 + min(0.6, cycle × 0.15) + min(0.5, max(0, day − 24) / 120)
target     = cur + delta × difficulty + floor(day × ramp)
```

- 周目每 +1 难度 +15%（上限 +60%），第 24 日后随时间线性变陡（上限 +50%）；
- 系数存入 `dailyObjective.scale`，达成时功业奖励同步放大 `round(merits × scale)`；
- 因为要务跨日持久、进度累积，高目标可以在多日内完成，不会变成死任务。
