# 18 · G4 策划案：从章节切片到可玩的修仙宗门

> 版本：0.2 · 已确认（按推荐）  
> 这一版先不写代码，先把“游戏到底怎么玩”定下来。  
> 目标不是 3A 开放世界，而是一个 **建筑可见、事件有随机、等级会展开、玩家能规划** 的单机修仙宗门。

---

## 18.0 一句话

> **你继承一座破落山门，在灵田、丹房、剑坪、藏经阁之间做取舍，接住每天随机出现的候选事件，把宗门从“破落山门”养成“一流宗门”。**

---

## 18.1 现在的问题

| 问题 | 具体表现 | 设计层原因 |
|------|----------|------------|
| 可玩度差 | 每天五个下拉 + 结束今日 | 决策太少，且没有风险 |
| 剧情少 | 12 天 6 个主事件 | 事件是线性投放，不是可选择的池 |
| 建模粗糙 | 基础几何体、比例单一 | 没有统一美术方向 |
| 穿模 | 玩家/弟子/群像/镜头互相穿 | 没有动态碰撞与镜头遮挡 |
| 自由发挥少 | 固定 12 天、固定事件 | 没有沙盒循环与等级展开 |
| 建筑没有存在感 | 建筑只是背景 | 经营系统没有和 3D 实体绑定 |

**结论：不是内容不够多，是“玩家做的决定”不够多。**

---

## 18.2 三个支柱

### 支柱一：宗门是看得见的

- 每个系统都有 **实体建筑**：
  - 灵田、药圃、丹房、剑坪、藏经阁、试剑台、弟子居、膳堂、库房、坊市、聚灵阵、山门阵、闭关洞府、灵兽栏、镇宗塔。
- 建筑有 **等级**，升级后外观变化：
  - 茅棚 → 木屋 → 石殿 → 重檐楼。
- 玩家可以在 **3D / 俯瞰** 两种视角里点击建筑，打开它的功能。
- 建筑之间 **有位置关系**：
  - 药圃靠近灵田；丹房靠近药圃；剑坪靠近山门；藏经阁远离膳堂；聚灵阵压在灵脉上。

### 支柱二：每天都有“候选”，不是“固定剧情”

- 每天从事件池抽 **3 张候选事件**，玩家选 1 张处理，或全部不理。**P4 已实现三候选、跳过与主线延后；种子/风险标签/冷却已在 [docs/24](24-strategy-depth-pass.md) 补齐。**
- 事件有等级、风险、前置、人物、后果。
- 主线/人物弧线是 **保底链**，不会被随机池冲掉。
- 随机不是纯随机：有 **权重、保底、预告、种子**。

### 支柱三：等级展开

- **宗门等级** 0-5：破落山门 → 三流小宗 → 二流 → 一流 → 大宗 → 圣地。
- 等级解锁：
  - 新建筑、建筑等级上限、地块、弟子上限、事件等级、区域、天劫。
- **掌门境界** 炼气 → 筑基 → 金丹 → 元婴，决定个人行动与天劫。
- **弟子境界** 决定可接任务与事件。
- 季节/年份推进，宗门不是 12 天就结束。

## 18.3 核心循环

### 日循环（5-10 分钟）

1. **晨报**
   - 资源、维护费、弟子状态、建筑进度。
   - 抽 3 张候选事件。
2. **安排**
   - 弟子派工：建筑岗位 / 采集 / 巡逻 / 修炼 / 休养。
   - 建造/升级：选地块、付资源、派建造弟子、排队。
   - 掌门行动：打坐 / 炼丹 / 巡视 / 外出 / 处理事件。
3. **事件**
   - 选 1 张候选，或跳过。
   - 需要的人/资源/建筑不足时，成功率下降。
4. **结算**
   - 产出、维护、事件结果、关系、伤势、突破。
5. **夜**
   - 随机小事件、弟子对话、建筑完工。

### 周循环

- 周结算：维护费、声望、宗门经验、弟子月钱。
- 周事件：宗门评议会、坊市大集、秘境开启。
- 周报：本周产出/损耗/关系变化。
- **周计划**：玩家可以一次排好一周，减少点击疲劳。

### 季节/年

- 春夏秋冬，每季 30 天。
- 季节影响：灵田产量、药材种类、事件池、天劫窗口。
- 年龄/寿元/宗门大事。
- 12 天章节保留为 **序章**；之后进入自由修行。

> 第一版 G4 只做 **日循环 + 候选事件 + 宗门等级**；周/季节先留接口。

## 18.4 地图与建筑实体

### 山门布局（固定地块，不做自由网格）

不做“随便摆”的网格，做 **固定地块 + 相邻加成**：

- 保证每栋建筑都好看、有路径、有门。
- 玩家选“这块地建什么”，不是“拖到哪”。
- 每块地有：
  - 地形、朝向、相邻地块、灵气浓度。
- 相邻加成示例：
  - 药圃 + 灵田：药材 +10%
  - 丹房 + 药圃：丹药产出 +15%
  - 剑坪 + 山门：弟子剑修训练 +10%
  - 藏经阁 + 弟子居：研习 +10%
  - 聚灵阵 + 灵脉：全宗门修炼 +20%

### 建筑表（第一版 14 栋）

| 建筑 | 等级 | 功能 | 升级外观 |
|------|------|------|----------|
| 山门 | 0 | 声望、访客、宗门等级 | 木门 → 石牌坊 → 重檐山门 |
| 主殿 | 0 | 议事、宗主、主线 | 单层 → 双层 → 重檐大殿 |
| 弟子居 | 0 | 弟子上限、休息 | 茅屋 → 院落 → 楼阁 |
| 膳堂 | 0 | 道心、月钱、宴席 | 棚 → 堂 → 楼 |
| 库房 | 0 | 资源上限、防窃 | 木仓 → 石仓 → 阵库 |
| 灵田 | 0 | 药材、灵谷 | 田 → 梯田 → 灵田 |
| 药圃 | 1 | 稀有药材、药庐 | 篱笆 → 药庐 → 药园 |
| 丹房 | 1 | 炼丹、丹方 | 炉棚 → 丹房 → 丹殿 |
| 剑坪 | 1 | 剑修训练、剑意 | 石坪 → 剑台 → 剑阵 |
| 藏经阁 | 2 | 功法、研习 | 书架 → 阁 → 重楼 |
| 试剑台 | 2 | 斗法、弟子考核 | 木台 → 石台 → 擂台 |
| 坊市 | 2 | 交易、情报 | 摊 → 街 → 市楼 |
| 聚灵阵 | 3 | 全宗门修炼 | 石阵 → 灵阵 → 大阵 |
| 山门阵 | 3 | 防御、巡山 | 旗 → 阵眼 → 护山大阵 |
| 闭关洞府 | 3 | 掌门/弟子突破 | 洞 → 府 → 灵府 |
| 镇宗塔 | 5 | 宗门底蕴、天劫 | 塔 → 灵塔 → 镇宗塔 |

### 建筑等级

- 每栋 0-3 级（镇宗塔 0-2）。
- 升级条件：资源 + 宗门等级 + 建造时间 + 建造弟子。
- 每级：
  - 外观变化（至少 3 个剪影阶段）。
  - 岗位数 +1。
  - 效果提升。
  - 维护费提升。
- 建造中显示脚手架、木料、工匠；完成后换模型。

### 地图模式

- **行走模式**：远第三人称，角色小，看山门。
- **俯瞰模式**：45-55° 俯视，平移/缩放，点击建筑/地块。
- 俯瞰时时间可暂停/1x/2x。
- 建筑头顶显示：
  - 名称、等级、岗位、建造进度。
- 空地块显示可建造图标。

## 18.5 镜头与角色尺度

- **不做第一人称**。
- 默认远第三人称：
  - 角色约占屏幕 1/6 高。
  - 相机距离 10-14m，俯角 35-42°。
  - 可拉远到 20m 看全景，拉近到 5m 看人。
- 俯瞰：
  - 距离 25-60m，俯角 45-55°。
  - WASD/拖拽平移，滚轮缩放。
- 角色模型保持 1.8m，不做“缩小人”；用镜头距离解决“人太大”。
- 镜头遮挡：
  - 建筑/树/地形自动拉近；
  - 太近时隐藏玩家模型，避免看到后脑勺/剑穿模。

## 18.6 事件系统：候选、随机、等级

### 候选卡

每天生成 3 张候选事件：

```
[灵田歉收]  等级 1 · 生产
风险：低
若处理：灵田产量 -20% 或 花费灵石补救
需要：灵田/苏晚照
```

- 玩家可：
  - 选 1 张处理；
  - 跳过全部（声望/道心代价，但安全）；
  - 让弟子代为处理（消耗弟子行动）。
- 候选来自 **事件池**，按条件过滤：
  - 宗门等级、季节、建筑、人物、旗标、境界。
- 事件等级：
  - 1 传闻（小事）
  - 2 事务（资源/关系）
  - 3 要事（人物/建筑/区域）
  - 4 大劫（宗门/天劫/战争）
- 高等级事件有 **预告**：
  - 坊市消息、弟子汇报、异象。
  - 玩家可以提前准备（建阵、炼丹、提升弟子）。

### 随机与公平

- 每天用 **存档内种子** 生成候选，读档不重 roll。
- 同一事件 N 天内不重复。
- 主线/人物弧线有 **保底触发**，不被随机池挤掉。
- 高风险事件显示 **成功率/失败后果**，不是黑箱。
- 判定：弟子属性 + 建筑 + 准备 + 丹药 + 一点骰子。
- 失败不是“读档”，而是：
  - 受伤、掉资源、建筑损坏、关系下降、事件链转向。

### 事件类型

| 类型 | 例子 | 后果 |
|------|------|------|
| 生产 | 灵田歉收、药圃虫害 | 资源、建筑 |
| 人物 | 弟子争执、走火入魔、旧仇 | 关系、去留 |
| 外事 | 散修投奔、大宗使者、魔道探子 | 声望、盟约 |
| 机缘 | 灵脉异动、古洞、剑冢 | 功法、区域 |
| 灾劫 | 山火、兽潮、天劫 | 建筑、弟子、寿元 |
| 商路 | 坊市行情、行商 | 灵石、药材 |
| 主线 | 三宗大比、宗门战争 | 章节、结局 |

### 例子：候选三选一

**第一日 · 晨报**

1. **【流民】** 山门外来了二十多个流民，想入宗。
   - 收留：弟子 +2、粮食 -20、声望 +3
   - 拒绝：道心 -2
   - 筛选：需要苏晚照，弟子 +1、声望 +1
2. **【灵田虫害】** 灵田出现碧线虫。
   - 用药：药材 -15，保住产量
   - 火烧：灵田产量 -30%，但断根
   - 不管：产量 -50%，可能蔓延
3. **【旧剑】** 剑冢里多了一柄没有名的断剑。
   - 悟剑：心得 +5，可能习得剑法
   - 收起：库房 +1，人物好奇
   - 不动：留下伏笔

> 玩家只能选 1 张；另外两张会过期，或产生小后果。

## 18.7 等级展开

### 宗门等级

| 等级 | 名称 | 解锁 | 弟子上限 | 地块 |
|------|------|------|----------|------|
| 0 | 破落山门 | 山门/主殿/弟子居/灵田/库房/膳堂 | 7 | 6 |
| 1 | 三流小宗 | 药圃/丹房/剑坪/试剑台 | 10 | 9 |
| 2 | 二流宗门 | 藏经阁/坊市/客院 | 14 | 12 |
| 3 | 一流宗门 | 聚灵阵/山门阵/闭关洞府 | 18 | 16 |
| 4 | 大宗 | 灵兽栏/镇宗塔/秘境 | 24 | 20 |
| 5 | 圣地 | 天劫/宗门战争/传承 | 32 | 24 |

晋级条件：

- 声望、建筑总等级、弟子境界、主线节点、资源储备。
- 晋级事件：宗门评议会/大宗使者/山门大典。
- 晋级不是自动，是 **玩家选择**：先扩弟子还是先建阵？

### 掌门境界

- 炼气 1-9 → 筑基 → 金丹 → 元婴。
- 每境解锁：
  - 个人行动（闭关、远行、天劫）。
  - 新区域。
  - 新事件等级。
- 境界不足时，高等级事件只能派弟子。

### 弟子境界

- 炼气 → 筑基 → 金丹。
- 弟子境界影响岗位、事件、关系。
- 弟子突破需要资源/丹药/护法；失败会受伤/掉境界。

### 季节

- 春：灵田、招新。
- 夏：兽潮、暴雨。
- 秋：大比、丰收。
- 冬：闭关、天劫、年关。
- 每年一次 **宗门大比**；每三年一次 **宗门战争**。

## 18.8 策略深度

玩家每天要做的不是“点满”，而是选：

- **地**：这块地建灵田还是丹房？
- **人**：苏晚照去药圃还是丹房？顾长风去剑坪还是巡山？
- **钱**：现在升级建筑，还是留灵石应急？
- **险**：接高风险事件，还是跳过？
- **时**：先闭关突破，还是先处理外事？
- **关系**：让谁去处理，谁和谁一起，谁会被冷落？

**没有“全都要”**：

- 地块有限。
- 弟子有限。
- 行动点有限。
- 维护费会压人。
- 事件会抢时间。

## 18.9 UI/UX

- **主界面**：
  - 左上：宗门、等级、资源、日期。
  - 右上：舆图、宗门簿、设置。
  - 底部：当前交互提示。
- **建筑点击**：
  - 直接打开该建筑面板（生产/岗位/升级/事件）。
  - 不再所有东西都塞进一个宗门簿。
- **晨报**：
  - 3 张候选事件卡，横向排列。
  - 卡面：标题、等级、风险、需要、后果预览。
- **周报**：
  - 产出、损耗、关系、建筑进度。
- **地图**：
  - 建筑等级、岗位、建造进度、事件图标。
- **减少点击**：
  - 支持“沿用上周安排”。
  - 支持批量派工。
  - 支持一键收菜/一键交付。

## 18.12 分阶段

- 确认本策划。
- 确认：固定地块 / 3 候选 / 日循环 / 远第三人称 / 14 栋建筑。

- 远第三人称 + 俯瞰。
- 12-16 块地块。

- 点击建筑打开面板。

### Phase C · 规划循环

- 建筑升级/岗位/相邻加成。
- 弟子派工。
- 维护费/周报。
- 行动点。

- 3 候选事件。
- 30 个事件。
- 宗门等级 0-5。
- 种子/保底/预告。

### Phase E · 人物与主线

- 沈青梧/顾长风/陆小满三条弧线。
- 主线 5 节点。
- 4 结局。

### Phase F · 美术与手感

- 低多边形水墨建筑/角色。
- 手臂/待机/行走。
- 镜头/碰撞/穿模。
- 性能。

## 18.13 验收标准

- 玩家能在 3D 山门里看到 **每一栋已建建筑**，并点击进入。
- 建筑升级后 **外观变化**。
- 每天有 **3 张候选事件**，选 1 张；读档不能重 roll。
- 宗门等级提升后，解锁 **新建筑/新事件/新地块**。
- 一次开局至少能玩 **2-3 小时**，不是 20 分钟结束。
- 玩家能说出至少 3 个“我做的取舍”。
- 穿模/镜头问题达到“可接受”，不是完美。

## 18.14 已确认的 5 件事

1. **建筑摆放**：固定地块（推荐）还是自由网格？
2. **事件候选**：每天 3 选 1（推荐），还是 1 个必做 + 2 个可选？
3. **循环节奏**：日循环（推荐）还是周循环为主？
4. **镜头**：远第三人称 + 俯瞰（推荐），还是只保留远第三人称？
5. **第一版建筑数量**：14 栋（推荐）还是先 8 栋？

> 已按推荐确认并进入 Phase B：固定地块、每天 3 选 1、日循环、远第三人称+俯瞰、先 8 栋做深。
