## 27.1 宗阶被动增益（Sect Perks）

宗阶不再只是头衔，而是即时体感。每阶对应一组香火被动：

| 宗阶 | 香火 |
|---|---|
| 败落遗宗 | 无 |
| 三流宗门 | 灵石/药材 +2 |
| 二流宗门 | 灵石/药材 +3 |
| 一流宗门 | 灵石/药材 +4 · 心得 +1 · **行动 +1** |
| 一方名门 | 灵石/药材 +5 · 心得 +1 · 声望 +1 · **行动 +1 · 候选 +1** |
| 霸主宗门 | 灵石/药材 +7 · 心得 +2 · 声望 +1 · 行动 +1 · 候选 +1 |
| 万古圣地 | 灵石/药材 +10 · 心得 +3 · 声望 +2 · **行动 +2 · 候选 +1** |

- 每日被动写入日终结算「宗阶香火「X」」一行；
- **行动点从固定 3 变成动态上限**（`game.maxActionPoints`），HUD 与宗门簿同步显示 `3/4`；
- 候选牌上限从固定 3 变成 3+（名门起 4 张）。

实现：`SECT_PERKS / sectPerk()`（[state.ts](../prototype/src/game/state.ts)），`Game.perk / maxActionPoints / processSectPerk`（[game.ts](../prototype/src/game/game.ts)）。

## 27.2 离宗弟子 · 寻回支线

离宗不再是终点：

- 七名弟子各有一段生成的寻回事件 `recall_*`；
- 当 `departed` 里有该弟子、且未处理过 → 每日**必然出现**一张寻回卡；
- 三个方向：**亲自去寻**（花灵石、忠心回满）、**派人去请**（省钱但忠心略降）、**就此作罢**（道心 +3）；
- 寻回通过 `Effect.recall` 重新激活弟子、清伤、移出 `departed`，结局扣分也随之取消。

实现：`RECALL_EVENTS`（由 `baseDisciples` 生成）+ `effect.recall` 处理。
