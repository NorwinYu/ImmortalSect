# 33 · 香火天梯（功业溢出兑换）

> G7.2 · 把自由修行里“功业只涨不花”的溢出，变成一条可兑换永久增益的香火天梯。冒烟回归 44 → 46 项。

---

## 33.1 动机

长线验证发现：功业抵达万古圣地（500）后仍继续累积却再无出口。本辑引入第二货币「香火」，给长线经营一个真正的消费端，也让“功业/宗阶/要务”这一整套经营层在自由修行里有持续回报。

## 33.2 香火来源

- 每日要务达成：**香火 +1**（叠加在功业 +8~14 之上）；
- 宗阶晋升：每新跨一阶 **香火 +2**（一次性）。

## 33.3 香火天梯（四项可兑换的永久增益）

| 项 | 效果 | 档位 / 消耗 |
|---|---|---|
| 灵脉回春 | 药材/灵石日获 +2/+4/+6 | 3 级，香火 3/6/9 |
| 洗剑池 | 弟子每日修炼 +0.5/+1.0/+1.5 | 3 级，香火 4/8/12 |
| 护山大阵 | 声望 +1/+2 日，弟子离山概率下降 | 2 级，香火 5/10 |
| 渡劫护符 | 天劫威势 -5%/-10% | 2 级，香火 6/12 |

“洗剑池”折入 `resolveTask` 的修炼公式；“护山大阵”折入 `applyStrain` 的离山判定；“渡劫护符”折入 `main.ts` 的天劫 boss 缩放（下限 1.0）。

## 33.4 接线改动

- `state.ts`：新增 `sectFaith / faithBought / faithRankIndex` 字段 + `FAITH_BOONS / faithBoon / faithLevel`；
- `saves.ts`：`normalizeState` 迁移三字段（旧档安全）；
- `game.ts`：`evaluateObjective` 香火 +1；新增 `processFaith`（晋升香火 + 被动产出）、`spendFaith`、`faithBoonLevel`；
- `ui/game-ui.ts`：面板底栏「香火 N」、`master-actions` 增「香火天梯」按钮与 `showFaithLadder` 会话框；
- `main.ts`：渡劫护符折入 `onTribulation` 的 bossScale。
