# 28 · 新周目（New Game+）

> G5.4 · 让十二日章节与自由修行真正首尾相接：结算后不必归零，而是带着宗门功业重开下一周目。冒烟回归 33 → 34 项。

---

## 28.1 结算后的第三个选择

章末结算现在有三个出口：

| 按钮 | 效果 |
|---|---|
| **二周目 · 功业 N 结转**（主） | 保留 `sectMerits`（宗阶随之留存），进入下一周目 |
| 再开一局 | 彻底归零重开（功业清零） |
| 留在山门 | 进入自由修行（原行为不变） |

## 28.2 结转规则

`Game.newGamePlus()`：

- 保留 `state.sectMerits`，宗阶与香火被动**从第一日就生效**；
- `cycle` +1（周目数），宗门簿页脚显示「第 X 周目」；
- 重掷开局际遇，并给一点起步灵石（`20 + 周目 × 10`）作为旧功业的好处；
- **已跨越的时代事件提前标记为 done**，避免在二周目重复触发旧里程碑、只有新跨越的宗阶才出新的时代事件；
- 弟子、旗标、事件、日期全部重置，回到第一日序章。

## 28.3 周目特效（Cycle Gifts）

更高周目不止多一点点灵石，而是越玩越花：

| 周目 | 起始赠礼 |
|---|---|
| 二周目 | 灵石 +30 · 丹药 +1 |
| 三周目 | 灵石 +40 · 丹药 +1 · **传授「霜刃」** · 心得 +2 · 道心 +3 · 气海 +10 |
| 四周目 | 灵石 +60 · 丹药 +2 · 霜刃 · 心得 +4 · 道心 +6 · 气海 +20 |
| 五周目 | 灵石 +80 · 丹药 +2 · 霜刃 · 心得 +6 · 道心 +9 · 气海 +30 |
| 六周目 | 灵石 +100 · 丹药 +3 · 霜刃 · 心得 +8 · 道心 +12 · 气海 +40 |

（六周目起封顶，灵石仍随周目递增。）「霜刃」是第二门功法，可小幅度提高破境成功率。

## 28.4 验收

- 冒烟回归 33 → **35 项**，新增「功业结转 / cycle+1 / 已跨时代事件标记 / 三周目传授霜刃与额外丹药」；
- 性能不变：山门 207 calls / 0.68 M 三角面，试剑 257 calls / 0.33 M 三角面；
- 版本 0.13.0，旧档迁移 `cycle=0`。
