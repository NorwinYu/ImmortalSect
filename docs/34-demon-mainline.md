# 34 · 魔道仇敌主线（跨章反派弧）

> G7.3 · 把散落在人物秘密里的“灭门旧案”暗线，收束成一条四幕反派主线，给自由修行一个真正的对手与终局回响。冒烟回归 46 → 47 项。

---

## 34.1 动机

白芷的药人身份、沈青梧的灭门、玄真守夜守住的真相、以及章节里那声“山门外那个人还会回来”——都被铺垫成零散的暗线，却始终没有交手。本辑把它们串成一个反派弧：青云宗越兴旺，越引来当年放魔道进山的旧主。

## 34.2 四幕结构（`demonChain` 0→1→2→3→4）

| 幕 | 触发 | 内容 |
|---|---|---|
| `demon_1` 阴风乍起 | 自由修行 + 功业 ≥ 150（一流宗门） | 魔道探子留药人牌，三方处置 |
| `demon_2` 旧主亲至 | 链 1 | 魔道旧主索要白芷/沈家断剑，拒/拖/买断 |
| `demon_3` 山门夜战 | 链 2 | 决战：亲战（境界+剑意）／布阵（道心+备战）／唤旧故（耗灵石），带成功率判定 |
| `demon_4` 尘埃落定 | 链 3 | 收束群像，白芷烧掉最后的药人牌 |

- 决战选项用 `option.check` 的成败判定（胜 +功业/声望/道心；败扣声望道心、掌门受伤、`demonLost`）；
- `demon_1` 在免费修行中作为**优先主牌**（`nextDemonEvent` 先于人物弧线），不会被冷落；
- 结局群像按 `demonWon/demonLost` 出对应文案。

## 34.3 接线改动

- 新增 `src/game/demon.ts`（`DEMON_EVENTS` + `nextDemonEvent`）；
- `state.ts`：`getEvent` 回退链加入 `DEMON_EVENTS`；`Effect` 增加 `merits / faith / playerInjury` 三种通用键；
- `game.ts`：`buildCandidates` 自由修行优先出魔道主牌；`applyEffect` 处理 `merits/faith/playerInjury`；`buildEpilogues` 增魔道结局文案；
- 冒烟回归新增「demon：四幕链推进 → 链 4 · 功业 +X」。

## 34.4 验收

- 冒烟回归 **47 项** 全绿；`demon_1→4` 按序推进、链标 4、功业随决战结算；
- 版本 0.20.0。
