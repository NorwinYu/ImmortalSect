# 26 · 宗门进阶：宗阶、时代事件与更多山中事

> G5.2 · 给“经营”加上一条贯穿全局的上升曲线，并用更多事件把世界填厚。全部随存档持久化，冒烟回归 28 → 30 项。

---

## 26.1 宗阶（Sect Rank）

`state.sectMerits` 现在对接到一条七级阶梯：

| 功业 | 宗阶 |
|---|---:|
| 0 | 败落遗宗 |
| 30 | 三流宗门 |
| 80 | 二流宗门 |
| 150 | 一流宗门 |
| 240 | 一方名门 |
| 350 | 霸主宗门 |
| 500 | 万古圣地 |

- 宗门簿页脚常驻「宗阶「X」· 功业 N · 在册 a，离山 b」；
- 宗阶只升不降，是自由修行里最长的一条目标线；
- 功业同时计入大比成绩（`min(12, merits×0.05)`），离宗弟子每人 −4。

实现：`SECT_RANKS / sectRank()`（[state.ts](../prototype/src/game/state.ts)）。

## 26.2 时代事件（Era Milestones）

每跨越一个宗阶，解锁一段只发生一次的时代事件，作为三候选里**必然出现**的一张卡，直到你处理它：

| 事件 | 触发宗阶 |
|---|---|
| 初露锋芒 | 三流宗门 |
| 修士来投 | 二流宗门 |
| 天骄来投 | 一流宗门 |
| 山门盟约 | 一方名门 |
| 名动一域 | 霸主宗门 |

每个时代事件带 2 个不同收益取向的选项（名利 vs 道心/稳妥），让“升阶”本身也是一次抉择，而不只是一个数字。

实现：`ERA_EVENTS` + `buildCandidates` 里的保底卡逻辑（[game.ts](../prototype/src/game/game.ts)）。

## 26.3 更厚的候选池

新增 2 个环境事件：

- **走失的野狐**（Lv.1 低风险）—— 影响因果与道心的道德抉择；
- **灵泉复涌**（Lv.2 中风险）—— 三种利用灵脉的取舍。

## 26.4 离宗与结局

- 弟子离宗时写入 `state.departed` 持久化；
- 页脚实时显示「在册 / 离山」人数；
- 离宗人数直接扣减大比成绩，让“冷落”在终局也有回声。

## 26.5 验收

- 冒烟回归 42 → **44 项**，新增「时代事件在升阶后必然出现」「宗阶名称显示」；
- 性能不变：山门 207 calls / 0.68 M 三角面，试剑 257 calls / 0.33 M 三角面；
- 旧档迁移：`departed=[]`；`sectMerits` 沿用既有归一化。

## 26.6 尚余空间

- 宗阶再接**被动增益**（每阶 + 行动点/产出/候选数），让升阶有即时体感；
- 时代事件扩展到**万古圣地**之后的“域界大比”；
- 离宗弟子的**寻回支线**（把 `departed` 变成可挽回的剧情）。
