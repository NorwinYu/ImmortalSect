# 29 · 天劫 3D Boss 战

> G6 · 把原设计里“天劫只是一次文本判定”的缺口补上：破入大境界（第九、十境）时，天劫化作雷劫形，逼你拔剑。冒烟回归 35 → 39 项。

---

## 29.1 从“掷骰子”到“拔剑”

破境一直是成功率掷骰。现在到达天劫门槛（进入第九境起）时：

- 点了「破境」后，天劫不再当场判定，而是**化形为 3D 傀儡**（蓝白雷光皮肤），进入完整试剑战斗；
- **赢** → 强制破境成功（入下一境、真气/寿元提升）；
- **败** → 破境失败（修为跌回、道心/伤势/寿元受损）。

三个选项不再只是成功率加减，而是改变这场 Boss 战的难度：

| 选项 | 天劫傀儡血量 |
|---|---|
| 稳守心神 | 1.35× |
| 以剑引雷 | **1.20×**（剑意劈雷，最易） |
| 服丹护体 | 1.28×（丹药 -1） |

## 29.2 实现

- `Game.beginTribulation(method)`：校验天劫门槛、扣丹药、写入 `pendingTribulation`；
- `Game.resolveTribulation(won)`：赢则破境、败则反噬，并清空挂起状态；
- `CombatSystem.start({ boss, bossScale })`：载入雷劫皮肤 + 血量缩放，胜负横幅改为「渡 劫 · 成 / 力 竭」；
- `SwordPuppet.setBoss(scale, tint)`：血量/架势按倍率缩放 + 符纹/眼瞳改蓝白雷光；
- `combat.onDefeat`：为挂起的天劫做失败结算（普通试剑失败仍是“再试一次”）；
- `pendingTribulation` 进存档与迁移（`normalizeState`），战斗中途退出/刷新不会丢状态；战斗走远退出会视为「暂避天劫」，清空挂起并复原傀儡。

## 29.3 验收
