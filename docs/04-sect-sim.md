# 04 · 宗门经营

> 经营层的唯一使命：**让玩家每天做 3 个有代价的决定**。

---

## 4.1 核心张力

宗门经营不是「造满建筑、升满科技」，而是三组永远拉扯的关系：

| 张力 | 左手 | 右手 |
|------|------|------|
| 快与稳 | 魔功/丹药速成 | 道心/根基/寿元 |
| 广与精 | 多收弟子、多开峰 | 资源稀释、内部派系 |
| 战与养 | 扩张、掠夺、立威 | 维护费、伤亡、外交恶化 |

> 如果玩家能「全部都要」，经营就失败了。

---

## 4.2 山门地图与灵气场

### 地图

- 起始：64×64 格（约 200m × 200m），带垂直落差（山门在谷地，三峰在后）。
- 可扩建：三峰 → 洞天福地（后期）。
- 放置：自由摆放 + 吸附网格；地形不可平整太多（保留山水感）。

### 灵气场（核心系统）

灵气不是全局数值，而是**空间场**：

```
灵气(x,y) = 地脉基础 + Σ 聚灵阵 + 灵泉/灵脉节点 - 建筑浊气
```

- **灵脉**：地图上 3-5 个节点，天然高灵气。
- **聚灵阵**：半径内 +灵气，多个阵法叠加递减（防止堆叠）。
- **浊气**：丹房/器坊/屠宰场降低周围灵气；弟子居需要清净。
- **风水**：背山面水 + 朝向 + 高度，给小幅加成（±15%），不做玄学复杂度。

> 玩家会自然地把「修炼区」和「工业区」分开——这就是布局策略。

### 季节与天象

- 春夏秋冬影响：灵田产量、灵气浓度、事件池。
- 天象：流星、血月、灵气潮汐、魔潮前兆。望星台可提前预报。

## 4.4 弟子系统

### 属性

| 属性 | 作用 |
|------|------|
| 灵根 | 修炼速度、术法属性（见 03） |
| 悟性 | 学习功法、顿悟概率 |
| 根骨 | 气血/防御/寿命 |
| 心性 | 道心稳定、抗心魔 |
| 魅力 | 外交、收徒、道侣 |
| 气运 | 随机事件、秘境掉落 |

### 隐藏属性

- **野心**（0-100）：高野心 + 低忠诚 → 叛变/夺权。
- **秘密**：身世、血债、魔道旧身份。被揭穿会触发事件。
- **寿元**：每个弟子都会老死，玩家要提前布局。
- **忠诚**：受待遇、职位、关系、理念影响。

### 性格标签（12 种）

勤奋、懒散、孤僻、仁善、狠辣、痴情、好斗、嗜酒、贪财、忠义、多疑、痴道。

- 影响 Utility AI 的权重（见 05）。
- 影响事件选项与关系建立。
- 没有「纯正面」性格：勤奋可能过劳，仁善可能放走敌人。

### 关系

| 关系 | 效果 |
|------|------|
| 师徒 | 修炼加成、传功、道心 |
| 道侣 | 修炼加成、心魔抗性、殉情风险 |
| 挚友 | 组队加成、事件互助 |
| 仇敌 | 内斗、暗杀、叛逃 |
| 血亲 | 忠诚、复仇链条 |

- 关系值 -100 ~ +100，可视化为关系网。
- 关系会**传播**：A 和 B 是仇敌，B 和 C 是挚友，A 对 C 的态度也会下降。

## 4.5 招募

| 方式 | 说明 | 风险 |
|------|------|------|
| 山门大比 | 每年一次，公开选拔 | 天才被其他门派截胡 |
| 下山游历 | 派弟子出去找 | 弟子可能受伤/叛逃 |
| 救人 | 事件触发 | 来路不明，可能是魔道卧底 |
| 联姻 | 与门派结亲 | 政治包袱、间谍 |
| 挖角 | 高价挖其他门派弟子 | 声望下降、被报复 |
| 魔道投奔 | 低成本高战力 | 道心/声望代价 |
| 遗孤 | 灭门后收养 | 长期投资，成长随机 |

> 招募的核心不是「抽卡」，是**判断人**：玩家要看出谁有潜力、谁有隐患。

---

## 4.6 职位与派系

### 职位

掌门 → 太上长老 → 峰主 → 长老 → 执事 → 真传 → 内门 → 外门 → 杂役。

- 职位给资源/权限/修炼加成。
- 空缺会降低效率；任人唯亲会引发不满。
- 掌门可以「禅让」，避免死后混乱。

### 派系

| 派系 | 主张 | 支持者 |
|------|------|--------|
| 保守 | 稳守山门、少惹事 | 老弟子、执事 |
| 激进 | 扩张、掠夺、立威 | 年轻弟子、战修 |
| 中立 | 平衡 | 多数 |
| 魔道 | 速成、禁忌功法 | 野心者、边缘人 |

- 派系有「影响力」数值；影响政策投票、事件走向。
- 玩家可以打压/拉拢，但过度打压会引发叛乱。
- **叛乱**是中期重要危机：弟子带资源出逃，甚至里应外合。

## 4.7 任务与派遣

| 任务 | 产出 | 风险 | 适配 |
|------|------|------|------|
| 采集 | 药材/矿石 | 低 | 杂役/外门 |
| 除妖 | 兽材/声望 | 中 | 战修 |
| 护送 | 灵石/人情 | 中 | 稳重弟子 |
| 探索 | 功法/秘境线索 | 高 | 气运高者 |
| 复仇 | 声望/因果 | 高 | 好斗者 |
| 卧底 | 情报 | 极高 | 多疑/魅力高者 |
| 传道 | 声望/信徒 | 低 | 仁善者 |

- 每任务 1-3 人，有「适配度」；不适配会降低成功率/增加事故。
- 结算用**报告**呈现（文字 + 小演出），关键任务可切换第三人称亲自处理。
- 失败不是「扣数值」，而是产生**故事**：弟子受伤、结仇、被俘、黑化。

## 4.8 经济

### 资源

| 资源 | 来源 | 用途 |
|------|------|------|
| 灵石 | 矿脉、任务、交易 | 通用货币、阵法维护 |
| 药材 | 灵田、采集 | 炼丹、疗伤 |
| 矿石 | 灵矿、探索 | 炼器、建造 |
| 兽材 | 狩猎、兽栏 | 炼器、符箓 |
| 法器 | 器坊、战利品 | 装备、交易 |
| 声望 | 事件、战争、传道 | 招募、外交、折扣 |
| 人情 | 帮助其他门派 | 一次性外交筹码 |

### 产业链

```
灵田 → 药材 → 丹房 → 丹药 → 自用/售卖
灵矿 → 矿石 → 器坊 → 法器 → 装备/售卖
兽栏 → 兽材 → 符箓/法器
```

- 玩家可以选择「卖原料」还是「做成品」：前者稳，后者利润高但需要人。
- 拍卖会（每季）：稀有物品竞价，声望影响入场资格。

### 通胀控制

- 固定支出：弟子俸禄、建筑维护、阵法灵石。
- 战争消耗：出兵、疗伤、抚恤。
- 事件回收：天灾、赔偿、被盗。
- 目标：玩家永远「差一点钱」，但不至于破产。

## 4.9 阵法

| 阵法 | 作用 | 玩法 |
|------|------|------|
| 聚灵阵 | 提升灵气 | 布局优化 |
| 护山大阵 | 守山战 | 塔防：阵眼、节点、灵力 |
| 迷阵 | 减速/绕路 | 影响敌人寻路 |
| 杀阵 | 范围伤害 | 配合地形 |
| 困阵 | 困住强敌 | Boss 战 |

- 阵法需要「阵法师」弟子维持；等级 = 阵法师水平 + 材料。
- 守山战：敌人从山门攻入，玩家布置阵眼/陷阱/弟子站位，实时指挥。
- 破阵：敌人也有阵法师，会寻找阵眼；玩家要保护。

> 护山大阵是「经营成果的可视化」：你建的每一座阵，都会在守山战里变成可操作的炮台。

## 4.10 事件

### 事件分类

| 类型 | 例子 | 频率 |
|------|------|------|
| 天灾 | 雷暴、山火、地脉枯竭 | 低 |
| 人祸 | 弟子叛逃、内斗、盗窃 | 中 |
| 机缘 | 秘境开启、顿悟、上古洞府 | 中 |
| 外交 | 联姻、求援、宣战 | 中 |
| 内部 | 派系斗争、继承争议 | 中 |
| 魔道 | 血祭、魔潮、蛊惑 | 低 |

### 事件结构

```
触发条件 → 开场（信件/演出） → 2-4 个选项 → 立即后果 → 延迟后果（发酵） → 传闻扩散
```

- 每个事件有「张力值」和「标签」，由导演系统调度（见 05）。
- 事件可以**压后**，但会发酵（例如：弟子受伤不治 → 死亡 → 其师复仇）。
- 事件结果会写入「宗门志」和「关系网」。

---

## 4.11 外交

- 12 个 AI 门派：正道 4、中立 4、魔道 3、隐世 1。
- 每个门派有：性格（好战/保守/贪婪/仁善）、目标、资源、关系网。
- 关系 -100 ~ +100：敌对 / 冷淡 / 中立 / 友好 / 同盟。
- 手段：遣使、送礼、联姻、结盟、附庸、宣战、贸易、情报。
- **声望**是全局修正：声望高，外交更容易；声望低，被群起攻之。

> 外交不是「点一下结盟」，而是**利益交换**：你需要我的灵矿，我需要你的功法，我们联姻。

## 4.12 战争

### 宣战理由

- 争夺灵脉/秘境
- 弟子被杀/被俘
- 盟友求援
- 魔道入侵（防御战）
- 玩家主动扩张（声望代价）

### 战争流程

```
宣战 → 集结 → 战役（3-5 场战斗） → 占领/赔款 → 和谈
```

- **守山战**：塔防 + 英雄单位，防御方有阵法优势。
- **远征**：派出队伍，补给线，地形/天气影响。
- **宗门战**：200v200，玩家指挥阵型/英雄/法术（见 06）。

### 后果

- 占领灵脉/建筑；俘虏弟子（可招募/赎金/处决）。
- 声望变化；其他门派态度连锁反应。
- 战争拖久 → 资源枯竭 → 内部不满 → 叛乱。

---

## 4.13 传承与结局

- **藏经阁**：功法/丹方/阵法图纸跨代保留；被毁 → 永久丢失。
- **道统**：掌门传功给继承人；继承人可能不服众 → 分裂。
- **宗门志**：自动记录大事，玩家可翻阅；结局时生成「百年史书」。
- **结局**：飞升 / 兵解 / 传承（宗门延续） / 灭门。

## 4.14 取舍设计清单（每个都要有代价）

| 决策 | 选项 A | 选项 B | 代价 |
|------|--------|--------|------|
| 灵药给谁 | 救重伤的弟子 | 炼筑基丹给天才 | 失去一个人 vs 失去一次突破 |
| 收徒 | 天才但野心高 | 平庸但忠诚 | 未来叛变 vs 上限低 |
| 建筑 | 丹房（赚钱） | 灵田（自给） | 现金流 vs 抗风险 |
| 功法 | 魔功速成 | 正道稳修 | 道心/寿元 |
| 战争 | 救援盟友 | 保存实力 | 声望 vs 安全 |
| 传承 | 传功给亲传 | 传给最有能力者 | 情感 vs 稳定 |
| 因果 | 杀俘立威 | 放俘收心 | 短期威慑 vs 长期声望 |

## 4.15 反例（不要做）

- ❌ 建筑可以全部造满，没有地皮/灵气冲突。
- ❌ 弟子只是数值卡，没有性格/关系/寿命。
- ❌ 任务自动完成，玩家只看结果，不做选择。
- ❌ 经济只涨不跌，后期灵石花不完。
- ❌ 外交是「好感度条」，送钱就结盟。
- ❌ 战争只是「战力对比」，没有战术/阵法/地形。
