# 25 · 可玩性深化：今日要务、宗门功业、弟子离心、开局际遇

> G5 · 从“能玩”到“有目标、有代价、每局不同”。在原有 12 日章节 + 自由修行的骨架上，补上四个延续可玩性的系统，全部随存档持久化，并纳入 28 项冒烟回归。

---

## 25.1 本轮要解决的问题

此前系统完整、性能达标，但站在“真实玩家”视角仍有三处松动：

1. **缺短期目标** —— 只知道“距三宗大比 N 日”，不知道今天具体追求什么；
2. **经营没有代价** —— 弟子被长期冷落也只是掉几点数据，不会真的离开，选择缺少压力；
3. **每局几乎一样** —— 重开一局的起点相同，逐局变化不足。

## 25.2 今日要务（Daily Objective）

每天结束时会先结算当日要务、再为次日掷一个新目标：

- 五类指标：`药材 / 灵石 / 心得 / 声望 / 宗门道心`；
- 目标值 = 当前值 + 单日增量 + 随日数递增的难度（声望/道心封顶 100）；
- 达成 → 按指标发放资源奖励 + 累加 **宗门功业（sectMerits）**；
- 未达成 → 结案显示差额，目标次日顺延到新掷出的目标（不存档卡死）；
- 目标与进度同时显示在宗门簿页脚和 3D HUD 的「距三宗大比」一行之后。

实现：`Game.rollObjective / evaluateObjective / objectiveDesc`；指标表 `OBJECTIVE_ROSTER`（[game.ts](../prototype/src/game/game.ts)）。

## 25.3 宗门功业（Sect Merits）

`state.sectMerits` 是贯穿整局、可跨自由修行的累计成就分：

- 每完成一次要务按难度加 8–14 点；
- 页脚常驻显示「宗门功业 N」；
- 为后续的声望阶梯 / 时代事件（下一轮）预留了唯一挂载点。

## 25.4 弟子离心（Strain / Departure）

给每位弟子加 `strain`（连续不适天数）：

- `mood < 30` 或 `injury ≥ 70` → +1；`mood ≥ 55` 且无伤 → −1（可回落）；
- strain 到 2 → 名册出现「心绪不稳」警示；
- strain 到 4 → 按 `0.25 + (1 − bond/100) × 0.6` 判定是否离开；
- 离开 → 移除岗位、从「在册」变「离山」、宗门声望 −2、掌门道心 −3，连锁影响建筑产出与大比成绩。

这让“谁要被冷落、谁要去安抚”成为真实决策，而非摆设。

## 25.5 开局际遇（Opening）

新开一局随机掷一个起始修正，随存档保存：

| 际遇 | 效果 |
|---|---|
| 名门之后 | 灵石 -20 · 声望 +10 |
| 药圃旧契 | 药材 +25 |
| 横财入库 | 灵石 +30 |
| 散修故交 | 心得 +5 |
| 债台高筑 | 灵石 -20 · 道心 +8 |

际遇写入首日纪事，并常驻页脚「开局「XX」」。修正 delta 已在 `createInitialState` 里落到资源与道心上。

## 25.6 验收

- 冒烟回归由 42 → **44 项**，新增「要务完成并顺延目标」「冷落导致弟子离宗」；
- 实测新增逻辑不影响性能：山门 207 calls / 0.68 M 三角面，试剑 257 calls / 0.33 M 三角面；
- 全部改动随 `version` 存档，旧档经 `normalizeState` 迁移（`strain=0`、`dailyObjective=null`、`sectMerits=0`、`opening` 默认「青云遗脉」）。

## 25.7 尚余空间

- 宗门功业接入**声望阶梯**（头衔 + 解锁时代事件）；
- 开局际遇扩展到**门规 / 祖训 / 掌门出身**（改变天赋与事件）；
- 弟子离宗后加入**寻回支线**；
- 把要务与候选事件联动（完成要务解锁高风险候选）。
