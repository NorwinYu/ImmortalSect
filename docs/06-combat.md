# 06 · 战斗

> 战斗是「修仙」最直观的爽点，也是 Web 性能最难的部分。本章只做三件事：**斗法、守山、宗门战**。

---

## 6.1 设计目标

1. **打得好看**：法术、剑气、雷劫要有电影感，截图能传播。
2. **打得明白**：每次死亡都知道为什么（五行被克？架势被破？没躲红圈？）。
3. **打得有选择**：功法/法宝/阵法/地形构成 Build，不是数值碾压。
4. **规模可伸缩**：1v1 到 200v200 用同一套底层规则。

---

## 6.2 三种战斗规模

| 规模 | 场景 | 玩家操作 | 时长 | 技术 |
|------|------|----------|------|------|
| **斗法** 1v1 | 切磋、复仇、天劫 | 动作 + 战术暂停 | 1-5 min | 全模拟 |
| **小队** 3v3 | 秘境、护送、除妖 | 动作 + 队友 AI | 3-8 min | 全模拟 |
| **宗门战** 200v200 | 守山、远征 | 战术俯视 + 英雄单位 | 10-20 min | 编队模拟 + LOD |

---

## 6.3 操作与资源

### 基础操作

| 输入 | 动作 |
|------|------|
| 左键 | 轻击 / 飞剑 |
| 右键 | 重击 / 蓄力 |
| 空格 | 闪避（无敌帧 0.2s） |
| Shift | 疾跑 / 御风 |
| Q / E | 术法 1 / 2 |
| R | 术法 3（大招） |
| F | 法宝 |
| Tab | 锁定/切换目标 |
| T | 战术暂停 |

### 三资源

| 资源 | 作用 | 恢复 |
|------|------|------|
| **体魄（HP）** | 生命 | 丹药、疗伤术、休息 |
| **真气（MP）** | 术法消耗 | 打坐、灵泉、吸血功法 |
| **神识（Focus）** | 大招/精准闪避/看破 | 缓慢回复、击杀回复 |

> 不做「蓝药水」：真气靠战斗节奏和功法回复，鼓励进攻。

### 架势（Poise）

- 类似《只狼》的躯干条：格挡/受击积累，满了破防，可处决。
- 重击/格挡成功会加速对方架势积累。
- 处决：高伤害 + 演出 + 回复神识。

## 6.4 五行与克制

### 相克

```
金 → 木 → 土 → 水 → 火 → 金
```

- 克制：伤害 ×1.3，破防 +20%。
- 被克：伤害 ×0.8，真气消耗 +20%。
- 同属性：×1.0，但可触发「共鸣」（同队同属性加成）。

### 相生（组合）

| 组合 | 效果 |
|------|------|
| 水 + 雷 | 感电：范围麻痹 |
| 火 + 风 | 蔓延：灼烧扩散 |
| 木 + 水 | 生长：持续治疗 |
| 土 + 金 | 坚壁：护盾 |
| 冰 + 火 | 蒸汽：致盲 |
| 暗 + 血 | 蚀骨：持续掉血 |

> 组合是「Build 的乐趣」：玩家会为了一个组合去凑功法，而不是只看稀有度。

### 环境

- **灵气浓度**：高灵气区域术法伤害 +20%，但更容易被雷劫锁定。
- **阵法**：敌我阵法区域提供 buff/debuff。
- **地形**：高地 +15% 射程；水中雷法扩散；狭窄地形限制闪避。

## 6.5 术法设计

每个术法有：

```
cost, cooldown, castTime, range, shape, element,
damageCoef, poiseDamage, tags, counterTags
```

### 类型

| 类型 | 例子 | 定位 |
|------|------|------|
| 投射 | 飞剑、火球 | 中距离 |
| 范围 | 雷池、火海 | 清群 |
| 控制 | 冰封、定身 | 辅助 |
| 增益 | 护体、加速 | 生存 |
| 位移 | 剑遁、缩地 | 机动 |
| 召唤 | 傀儡、灵兽 | 持续压力 |
| 反制 | 镜花水月（反弹） | 高端 |

### 设计原则

- 每个术法有**明确的反制方式**（闪避/格挡/位移/打断）。
- 不做「必中 + 高伤 + 无前摇」。
- 大招有**演出前摇**（1-2 秒），给对手反应时间。
- 术法之间用「标签」互动（如 `projectile` 可被 `reflect` 反弹）。

---

## 6.6 战术暂停

- 按 `T` 进入 0.2x 慢动作，可下达最多 3 个指令（移动/技能/目标）。
- 适合经营玩家：不想拼手速，但想拼策略。
- 联机（未来）不可用，单机专属。
- 自动战斗：可托管，但关键 Boss/天劫必须手动（或降低奖励）。

---

## 6.7 敌人与 Boss

### 敌人类型

| 类型 | 行为 | 弱点 |
|------|------|------|
| 妖兽 | 冲锋/扑咬 | 火/雷 |
| 魔修 | 吸血/召唤 | 木/净化 |
| 正道修士 | 阵法/剑阵 | 破阵/绕后 |
| 天劫化身 | 阶段机制 | 机制解谜 |
| 傀儡 | 高防/慢 | 雷/关节 |

### 精英词缀

- 狂暴（低血加速）
- 护体（需要破防）
- 分裂（死亡分裂）
- 反伤（不能无脑连）
- 隐匿（需要神识）

### Boss 设计原则

1. **3 阶段**，每阶段换一套招式 + 场地变化。
2. **可读的 telegraph**：红圈/前摇/音效，玩家能学会。
3. **处决/互动**：破防后处决，或场景机关（落石/雷柱）。
4. **叙事绑定**：Boss 是某个人/某段因果，不是血条。
5. **失败可学习**：死亡回放/提示，而不是单纯数值墙。

## 6.8 宗门战

### 结构

```
战前：编队（5 人一队）→ 布置阵型/阵法 → 选择目标
战中：下达移动/攻击/技能指令 → 英雄单位介入 → 士气/地形
战后：伤亡、俘虏、战利品、声望
```

### 单位

- **方阵**：普通弟子，5-20 人一组，用 Instancing 渲染。
- **英雄**：长老/掌门/真传，全模拟，可操作。
- **阵法**：范围 buff/debuff，可被破坏。
- **攻城器械**：傀儡、灵兽、飞舟。

### 士气

- 伤亡、主将死亡、被包围 → 士气下降 → 溃逃。
- 士气比血量更重要：一场仗的胜负往往在「谁先崩」。

### 性能

- 200v200：远处用 Impostor/简模，近处全模。
- 逻辑：编队级模拟（不是每个单位独立 AI），英雄单位独立。
- 目标：宗门战 60fps（独显）/ 30fps（核显）。

## 6.9 数值骨架

### 伤害公式

```
DMG = (ATK × skillCoef − DEF × 0.6)
      × elementMultiplier
      × critMultiplier
      × (1 − resist)
      × poiseMultiplier
```

- 最低伤害 1，防止完全免疫。
- 暴击 1.5x，暴伤可堆到 2.0x。
- 抗性上限 75%。
- 防御收益递减：`DEF / (DEF + 100)`。

### TTK 目标

| 目标 | 时间 |
|------|------|
| 杂兵 | 3-5 s |
| 精英 | 20-30 s |
| Boss | 3-5 min |
| 宗门战 | 10-20 min |
| 天劫 | 5-8 min |

### 数值原则

- **境界压制**：高一大境 = 基础属性 ×3，但可用阵法/群殴/克制弥补。
- **不搞无限连**：真气/架势/韧性三重限制。
- **Build 克制**：没有无敌 Build，只有「当前环境最强」。
- **难度可调**：故事/普通/困难/天劫，只影响 AI 进攻性与伤害，不改机制。

## 6.10 打击感（Game Feel）

| 手段 | 参数 |
|------|------|
| 顿帧（hitstop） | 轻击 60 ms，重击 120 ms，处决 200 ms |
| 屏幕震动 | 幅度随伤害，持续 0.1-0.3 s |
| 受击闪白 | 80 ms |
| 粒子 | 3 层：核心闪光 + 元素粒子 + 环境碎屑 |
| 音效 | 层次：破空 + 命中 + 元素 + 低频 |
| 镜头 | 处决/大招时 FOV 收窄 + 轻微推拉 |
| 手柄 | 支持（若时间允许），震动反馈 |

> 打击感是「3A 感」最便宜的部分：同样的模型，加 60ms 顿帧和音效，手感天差地别。

---

## 6.11 平衡与验证

- **石头剪刀布**：五行 + 三种防御（闪避/格挡/护盾）互相克制。
- **Build 多样性**：至少 5 种可行流派（剑修/雷法/体修/丹修/阵修/魔道）。
- **数据驱动**：所有数值在表里，可热更新。
- **模拟测试**：用脚本跑 10,000 场自动战斗，检查胜率/时长。
- **玩家测试**：观察死亡原因，是否「知道为什么死」。

---

## 6.12 反例（不要做）

- ❌ 站桩对轰，没有闪避/格挡/位移。
- ❌ 数值碾压，高一境必胜。
- ❌ 技能全是「伤害 + 范围」，没有机制差异。
- ❌ Boss 只会加血加攻，没有阶段/演出。
- ❌ 宗门战是「两堆数字相减」，没有指挥感。
- ❌ 自动战斗能通关一切，玩家没有介入欲望。
