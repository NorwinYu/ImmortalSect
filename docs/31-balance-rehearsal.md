# 31 · 策略平衡预演与调优

> G6.2 · 用自动化“好好玩”预演整局，实测四种玩法的结果分布，并据此修正评分权重与要务机制。冒烟回归 42 → 44 项。

---

## 31.1 预演方法

以真实游戏循环（Playwright 驱动 `window.__sect.game`，三枚固定随机种子 × 四种玩法）跑完十二日章节：

| 玩法 | 描述 |
|---|---|
| 摆烂流 | 全员休养，不打坐/送礼/闲聊/试剑/做要务 |
| 纯修炼流 | 全员修炼 + 1 人轮值巡山，不理要务 |
| 经营流 | 每天全力完成当日要务，其余修炼 |
| 混合流 | 修炼为主，要务顺手做 |

## 31.2 调优前发现的问题

1. **功业权重过低**：`min(12, merits×0.05)`，章节内满打满算 ~120 功业只值 6 分，而不做要务的纯修炼流照样 87 分拿魁首——**经营层对结局几乎没有影响**；
2. **要务每天强制重 roll**：昨天快完成的目标今天被换掉，经营流收益极不稳定（某种子 12 天只攒 28 功业）。

## 31.3 修正

- 评分公式：`境界×34 + 修为×16 + 声望×20 + 忠诚×18 + 试剑×3(≤9) + 功业×0.18(≤18) + 宗阶×3 − 离山×4 + 旗标加成`；
- **要务持久化**：未完成的目标跨日保留进度，完成后才重 roll 新目标（`rollObjective` 只在无目标或已完成时滚动）。

## 31.4 调优后实测分布

| 玩法 | 评分 | 结局 |
|---|---|---|
| 摆烂流 | 39–43 | 山门易主 |
| 纯修炼流 | 83–91 | 三宗魁首 |
| 经营流 | **83–100** | 三宗魁首（含满分） |
| 混合流 | 73–83 | 名列三甲 / 魁首 |

- 技术梯度 **40 → 100**：玩得差必输，玩得好封顶，最优解必须经营宗门；
- 经营层贡献从“≈2 分”提升到“**最多 ~24 分**”（功业 18 + 宗阶 6），约占总分四分之一；
- 三种认真玩法都能到魁首，但只有真正做要务才能摸到满分 100。
